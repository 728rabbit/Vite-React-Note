## 🧩 一、什麼是自訂 Hook？

你已經知道 React 有：

-   `useState`
    
-   `useEffect`
    
-   `useContext`
    
-   `useReducer`
    
-   `useMemo`
    
-   `useRef`
    

但有時候，我們會發現：

> 幾個元件都重複用到一樣的邏輯（例如資料存取、API 請求、scroll 監聽...）

這時候就可以把邏輯「抽出來」變成自己的 Hook。

----------

## 🌟 範例：把 localStorage 功能抽成 Hook

我們先從最常見的「儲存資料」開始。

### 🧱 原本寫法：

在 Todo 裡每次都寫：

    useEffect(() => {
      localStorage.setItem("todos", JSON.stringify(todos));
    }, [todos]);


這樣每個頁面都要重複寫，很煩 😩。

----------

### ✨ 改寫成自訂 Hook：`useLocalStorage`

src/hooks/useLocalStorage.js

    import { useState, useEffect } from "react";
    
    export function useLocalStorage(key, initialValue) {
      const [value, setValue] = useState(() => {
        const saved = localStorage.getItem(key);
        return saved ? JSON.parse(saved) : initialValue;
      });
    
      useEffect(() => {
        localStorage.setItem(key, JSON.stringify(value));
      }, [key, value]);
    
      return [value, setValue];
    }


----------

### 🧠 使用方法：

    import { useLocalStorage } from "../hooks/useLocalStorage";
    
    export default function TodoApp() {
      const [todos, setTodos] = useLocalStorage("todos", []);
    
      function addTodo(text) {
        setTodos([...todos, { id: Date.now(), text, done: false }]);
      }
    
      return (
        <div>
          <button onClick={() => addTodo("新任務")}>新增</button>
          <pre>{JSON.stringify(todos, null, 2)}</pre>
        </div>
      );
    }


✅ 現在資料會自動存在 localStorage  
✅ 關掉頁面再開，資料還在  
✅ 不用每個地方都重寫 `useEffect`

----------

## 🧩 二、自訂 Hook 的命名規則

1.  一定要用 `use` 開頭（例如 `useLocalStorage`、`useTheme`）
    
2.  裡面可以用 React 內建 Hook（例如 `useState`, `useEffect`）
    
3.  不要在普通函數裡使用 Hook（必須在元件或自訂 Hook 裡）

## 🧩 三、練習：主題切換（亮 / 暗模式）

這是另一個超常見的功能，也可以用自訂 Hook 實作。

src/hooks/useTheme.js

    import { useState, useEffect } from "react";
    
    export function useTheme(defaultTheme = "light") {
      const [theme, setTheme] = useState(() => {
        return localStorage.getItem("theme") || defaultTheme;
      });
    
      useEffect(() => {
        document.documentElement.className = theme;
        localStorage.setItem("theme", theme);
      }, [theme]);
    
      function toggleTheme() {
        setTheme((t) => (t === "light" ? "dark" : "light"));
      }
    
      return { theme, toggleTheme };
    }


----------

### 使用它：

    import { useTheme } from "../hooks/useTheme";
    
    export default function ThemeButton() {
      const { theme, toggleTheme } = useTheme();
    
      return (
        <button
          onClick={toggleTheme}
          className="bg-gray-200 dark:bg-gray-800 text-black dark:text-white px-4 py-2 rounded"
        >
          {theme === "light" ? "🌞 亮色模式" : "🌙 暗色模式"}
        </button>
      );
    }
