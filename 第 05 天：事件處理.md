
## 🧠 一、React 事件處理基礎

-   React 的事件寫法類似 HTML，但有幾個不同點：
    
    1.  **事件名稱用 camelCase**，例如 `onClick`、`onChange`
        
    2.  **事件處理函式要傳 function**，不是字串
        
        `<button onClick={handleClick}>按我</button>` 
        
    3.  可以直接用箭頭函式內聯：
        
        `<button onClick={() =>  setCount(count + 1)}>+1</button>`

## 🧩 二、練習 1：輸入框即時顯示文字

建立一個簡單的表單元件：

    import { useState } from 'react';
    
    function App() {
      const [text, setText] = useState('');
    
      return (
        <div>
          <h1>事件處理練習</h1>
          <input
            type="text"
            placeholder="輸入文字..."
            value={text}
            onChange={(e) => setText(e.target.value)} // 監聽輸入
          />
          <p>你輸入的是：{text}</p>
        </div>
      );
    }
    
    export default App;


-   說明：
    
    -   `value={text}` → 綁定 state
        
    -   `onChange={(e) => setText(e.target.value)}` → 每次輸入文字就更新 state
        
    -   `<p>` 會即時顯示輸入的內容

## 🧩 三、練習 2：表單提交

    import { useState } from 'react';
    
    function App() {
      const [name, setName] = useState('');
      const [submittedName, setSubmittedName] = useState('');
    
      function handleSubmit(e) {
        e.preventDefault(); // 防止頁面刷新
        setSubmittedName(name);
        setName('');
      }
    
      return (
        <div>
          <h1>表單提交練習</h1>
          <form onSubmit={handleSubmit}>
            <input
              type="text"
              placeholder="輸入名字"
              value={name}
              onChange={(e) => setName(e.target.value)}
            />
            <button type="submit">送出</button>
          </form>
          {submittedName && <p>你送出的名字是：{submittedName}</p>}
        </div>
      );
    }
    
    export default App;

-   點擊「送出」按鈕後，頁面不會刷新
    
-   會把輸入的名字顯示出來
    
-   可以觀察 `state` 的變化如何控制畫面
